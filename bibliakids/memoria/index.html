Como adicionar as imagens

Enquanto não há imagens, o jogo usa ícones coloridos

Crie uma pasta imagens ao lado deste arquivo HTML, com uma subpasta para cada tema (o nome exato está entre parênteses abaixo). Dentro de cada subpasta, salve as imagens numeradas de 1.jpg até 30.jpg:

    Exemplo de caminho: imagens/coragem/1.jpg

    Fácil usa 5 imagens (1 a 5) de cada tema, Médio usa 10 imagens (1 a 10) e Difícil usa 15 imagens (1 a 15). Cada imagem vira 2 cartinhas iguais no jogo. Formatos aceitos: .jpg, .png ou .webp (ajuste a extensão no código se preferir).
